# IR Ball Sensor Visualizer ⚽

ロボカップジュニアサッカー用 IRボールセンサー リアルタイム可視化デバッグツール

## 🚀 使い方

### GitHub Pages で使う（推奨）
1. このリポジトリの GitHub Pages URL にアクセス
2. Chrome または Edge で開く
3. 「接続」ボタンでシリアルポートを選択、またはモックモードでテスト

### ローカルで使う
1. `index.html` をダウンロード
2. Chrome または Edge で開く
3. そのまま使えます（インストール不要）

## 📡 通信仕様

| 項目 | 値 |
|---|---|
| 通信方式 | UART (USBシリアル変換経由) |
| ボーレート | 115200 bps（変更可能） |
| データ形式 | `角度,強度\n` |
| 未検知値 | 角度 `404` |

### データ例
```
45.0,186    ← 角度45.0°、強度186
0.0,250     ← 角度0.0°、強度250
404,0       ← ボール未検知
```

### データ形式のカスタマイズ
サイト上の「データ形式」パネルから以下を自由に変更できます：
- 区切り文字（カンマ、タブ、スペース等）
- 角度/強度のフィールド番号
- 未検知判定値
- 強度の最大値
- カスタムパースコード（上級者向け）

## ✨ 機能

- 🔌 **シリアル接続** - Web Serial API でUSBシリアルに直接接続
- 📡 **レーダーチャート** - 極座標グラフでボール位置をリアルタイム表示
- 🔴 **ボールプロット** - グロー＆パルスアニメーション付き
- 🚫 **未検知表示** - 角度404受信時に大きく「Ball Not Detected」表示
- 📊 **数値表示** - 角度・強度をテキストでリアルタイム表示
- 📈 **統計情報** - 受信数、受信レート(Hz)表示
- 📐 **データ形式設定** - 区切り文字やフィールド位置をUI上で変更可能
- 🧪 **モックモード** - 実機なしでテスト可能
- 🎨 **表示設定** - 軌跡表示、0°方向、回転方向を変更可能
- ⚡ **60FPS描画** - Canvas 2D APIによる軽量レンダリング

## ⚠️ 動作環境

- **Chrome** または **Edge** が必要です（Web Serial API対応ブラウザ）
- Firefox / Safari では シリアル接続は使用できません（モックモードは動作します）

## 🏗️ 技術スタック

- HTML / CSS / JavaScript（単一ファイル）
- Web Serial API
- Canvas 2D API
- 外部依存: なし（Google Fonts のみ）
